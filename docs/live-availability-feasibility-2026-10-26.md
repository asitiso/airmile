# 실제 마일리지 좌석 조회 가능성 검증 — 2026-10-26

## 검증 범위와 사실

1. **아시아나 공식 마일리지 좌석 조회**: 웹 조회 화면에 편도/왕복, 출발지·도착지·탑승월과 조회 버튼이 존재한다. 페이지 주의사항에 **전일 기준 일 1회 갱신, 360일 제공**이 명시되어 있다. 이는 좌석 수량이나 현재 발권 가능 보장이 아니다.
   - 출처: https://flyasiana.com/I/KR/KO/MileageSeatSearch.do
2. **대한항공 공식 공개 좌석 달력**: 공개 사용자 UI를 통한 월 단위 조회 성공을 기록한 2026-09-07 독립 오픈소스 사례가 존재한다. 독립 사례에서는 하루별 좌석 등급의 boolean 표식과 편명을 관찰했으나 실제 남은 좌석 수를 얻지 못했다. 해당 사례는 **우리 프로젝트에서 재현한 라이브 테스트가 아니다**.
   - 출처: https://github.com/we-insub/Korean_air/blob/main/docs/koreanair-public-flow.md
   - 공식 URL: https://www.koreanair.com/booking/book-and-manage/award-seat-availability
3. **외부 API**: Seats.aero는 파트너 API를 제공하지만 자체 SKYPASS/아시아나클럽 발권 가능 재고 지원을 아직 확인하지 못했다. 문서에 따르면 일부 라이브 조회에는 **5~15초**가 소요될 수 있어 최초 10초 목표와 충돌할 수 있다.
   - 출처: https://developers.seats.aero/reference/live-search
   - 정책: https://developers.seats.aero/reference/getting-started-p

## 데이터 수집 설계 관문 (Go / No-Go)

- **Go-1**: 항공사 웹사이트/제공자에서 허용되는 접근 방식, 약관/요청 제한을 확인
- **Go-2**: 인천→도쿄/뉴욕/파리에서 실제로 첫 1개월 조회, 좌석 등급·편명·날짜 대조
- **Go-3**: 제공 정보의 적시성과 정확성 측정. 공개 일일 스냅샷은 실시간이라고 표기 금지
- **Go-4**: 한번의 월별 응답에 월 전체 날짜가 있다면 날짜마다 재호출하지 않기. 수집 중 선택한 달을 최우선 처리
- **Go-5**: 실패/로그인 만료/조회 제한 시 일시정지, 재시도 제한. CAPTCHA 우회와 세션 쿠키 복제 금지
- **Go-6**: 사용자 경험 목표는 캐시 결과 2초, 신규 첫 결과 10초지만 실제 계측으로 검증
